Bowen Yuan
Researcher & Developer

I am Bowen Yuan, a PhD candidate in Computer Science at the Adelaide University, working at the intersection of Human–Computer Interaction, Augmented Reality, and AI. My research focuses on transforming expert demonstrations into adaptive, spatially grounded AR task guidance using multimodal signals such as gaze and motion, with publications in ACM CHI, IEEE VR, and ISMAR, and a broader goal of building intelligent systems that make complex real-world tasks more intuitive and efficient.

Adaptive Avatar Agents for Context-Aware VR Collaboration
This project explores how AI-driven avatar agents can support attention guidance, task review, and collaboration in immersive VR environments. The system records user behaviour during VR tasks, including head position, head direction, hand interaction, grabbed objects, voice, and task duration, then uses speech-to-text, vision-language models, and text embeddings to help the agent review and respond to user activity. A key focus is adaptive avatar embodiment: the agent can transform between different avatar types, such as humans, robots, animals, fish, birds, and animated objects, based on conversation context, task state, environmental events, and possible biological signals. The project aims to investigate how avatar diversity, transformation, and environment-aware behaviour can make AI agents more expressive, noticeable, and useful in VR task guidance and collaborative scenarios.

Facilitating Discussions in Immersive Virtual Meetings with Virtual Agents
This project investigates how proactive virtual agents can support collaboration in immersive virtual meetings. The system uses a cloud-based LLM service to track meeting agendas, transcripts, time remaining, and participant talk time, then provides timely facilitation such as introducing agendas, keeping time, encouraging quieter participants, and summarising discussion. A user study comparing passive and active agent behaviours suggests proactive facilitation can improve discussion support, while also requiring more nuanced timing to avoid distraction.

Gaze-Adaptive Diminished Reality for Attention Management
This project examines how Diminished Reality (DR) can be used to manage visual attention in AR by selectively reducing irrelevant information. Two approaches are explored: binary visibility and multi-level transparency based on gaze behavior. The system dynamically modulates scene visibility to guide attention without fully removing context. This work contributes to understanding how subtle visual suppression can improve focus in complex environments.

STAGE: Non-Linear AR Task Guidance via Dependency Modeling
This project introduces STAGE, a system that transforms expert AR recordings into structured, replayable task guidance using a Directed Acyclic Graph (DAG). Instead of linear video playback, it segments multimodal data (video, gaze, motion) into meaningful task units and models their dependencies. The system enables users to navigate tasks non-linearly while respecting procedural constraints. It aims to support flexible, real-world workflows where strict step-by-step sequences are insufficient.

Location-based Non-linear Playback of AR Task Recording
This project investigates a non-linear replay approach that automatically segments AR task recordings based on spatial location data. Instead of manual timeline scrubbing, the system enables reviewers to jump directly to task segments associated with their current physical location. A user study with 19 participants found that 89.5% preferred the location-based interface, reporting reduced mental and physical demand compared to conventional linear playback.

Focus-Aware AR Guidance: Adaptive Playback via Gaze and Location
This project explores how AR guidance can dynamically adapt to user attention using gaze and spatial context. By detecting whether users are engaged, distracted, or lost, the system adjusts playback speed or pauses automatically. Results show that adaptive guidance improves task accuracy and reduces manual control compared to static playback. The work highlights how minimal, well-chosen signals can outperform more complex multi-modal combinations.

Spatial Guidance Cues in AR: Line vs. Radar Navigation
This project investigates how different visual guidance cues affect user navigation in AR environments. Comparing line-based and radar-based cues, the study finds that egocentric line guidance significantly improves efficiency, reduces head movement, and enhances spatial orientation. Radar cues, while informative, introduce additional cognitive load when mapping 2D representations to 3D space. The findings emphasize the importance of intuitive, embodied visual design in AR systems.

The Fusion Nexus: Biocognitive Audio-Verbal Interface in Asymmetric XR Collaboration
FusionNexus is an asymmetric collaboration experience where a VR player guides a real-world player through pose-based tasks. A machine learning model performs real-time pose detection, while the VR player's heartbeat — captured via a Shimmer PPG sensor — controls drum beat tempo in background music, conveying emotional and physical state across realities. The two players collaborate to complete a timed challenge under immersive pressure.
